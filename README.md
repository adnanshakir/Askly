<h1>🤖 Askly – AI-Powered Q&A Platform</h1>

<p>
<b>Askly</b> is a full-stack AI-powered web application that enables users to ask questions and receive intelligent, structured responses using modern LLM integrations and real-time web search.
</p>

<p>
The project focuses on building a <b>scalable AI interface</b> with clean UI, efficient model handling, and reliable fallback mechanisms.
</p>

<hr>

<h2>✨ Features</h2>

<ul>
<li>🧠 <b>AI-Powered Responses</b> – Integrated <b>Gemini Flash</b> for generating fast and contextual answers</li>
<li>⚡ <b>Smart Title Generation</b> – Uses lightweight models for efficient and fast title creation</li>
<li>🔁 <b>Model Fallback System</b> – Automatically switches to Gemini when token limits are reached (e.g., Mistral fallback)</li>
<li>🌐 <b>Web Search Integration</b> – Uses <b>Tavily API</b> to fetch real-time, relevant information</li>
<li>📝 <b>Rich Response Rendering</b> – Displays AI responses using <b>React Markdown</b> for structured output</li>
<li>🔐 <b>Email Verification System</b> – Only verified users can access the chat functionality</li>
<li>📩 <b>Email Service</b> – Implemented using <b>Nodemailer</b> for user verification workflow</li>
<li>🎨 <b>Modern UI</b> – Clean and responsive interface built with <b>Tailwind CSS</b></li>
</ul>

<hr>

<h2>🧠 Key Implementations</h2>

<ul>
<li><b>Multi-model architecture</b> with fallback handling for reliability and uninterrupted user experience</li>
<li><b>API orchestration</b> combining LLM responses with real-time web search results</li>
<li><b>Secure authentication flow</b> using email verification before granting access</li>
<li><b>Structured response rendering</b> using markdown parsing for better readability</li>
<li><b>Clean folder structure</b> and modular code for scalability and maintainability</li>
</ul>

<hr>

<h2>🛠 Tech Stack</h2>

<ul>
<li><b>Frontend:</b> React, Tailwind CSS</li>
<li><b>Backend:</b> Node.js, Express</li>
<li><b>AI Models:</b> Gemini Flash, Mistral (fallback handling)</li>
<li><b>APIs:</b> Tavily (web search)</li>
<li><b>Email Service:</b> Nodemailer</li>
</ul>
